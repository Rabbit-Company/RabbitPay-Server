# Timesheets, tickets and payroll

Log working hours and absences, plan work with tickets and calculate pay, all following Slovenian employment rules.

| I want to                                  | Page                                       |
| ------------------------------------------ | ------------------------------------------ |

| Keep job, pay and personal details         | [Employee records](workforce/employees)    |
| Log hours and approve the month            | [Timesheets](workforce/timesheet)          |
| Request and approve vacation or sick leave | [Absences](workforce/absences)             |
| Sum up the month for payroll               | [Monthly report](workforce/monthly-report) |
| Plan work and bill the hours               | [Tickets](workforce/tickets)               |
| Calculate pay, payslips and REK-O          | [Payroll](workforce/payroll)               |

These parts of a project need a workforce license, which covers 5 people. Larger teams add employee seats. [Chat and calls](chat), the [calendar](calendar) and [files](files) come with it too.
