# Recurring expenses

Rent, subscriptions and other costs that repeat can be entered for you on a schedule.

## Set up a recurring expense

1. On **Expenses**, press **Add recurring expense**.
2. Fill in the **Description**, the **Supplier**, the **Category**, the **Total amount** and the VAT, as for a [single expense](expenses-and-reports/record-expense).
3. Set the **Start date or next date**.
4. Under **Repeat every** and **Period**, set how often, from 1 to 60 weeks, months or years.
5. Optionally set an **End date** or the **Maximum entries**.
6. Press **Add recurring expense**.

   ![A monthly rent](https://cdn.rabbitpay.net/help/en/dark/expenses-and-reports/recurring-expenses/form.webp)

Each entry is created as unpaid. Switch on **Mark generated expenses as paid** only for costs that are paid automatically, such as a direct debit. RabbitPay only records the expense and never sends a payment.

## Pause, change or stop it

The recurring expense is listed under **Recurring expenses**, with the date of its next entry.

![A recurring expense below the expense list](https://cdn.rabbitpay.net/help/en/dark/expenses-and-reports/recurring-expenses/schedules.webp)

- **Edit** changes it. Entries it already created stay as they are.
- **Pause** stops new entries until you press **Resume**.
- **Cancel schedule** ends it. Entries it already created stay in your reports.
