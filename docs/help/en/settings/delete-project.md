# Delete a project

Remove a project you no longer use. Invoices and payments are financial records, so they are kept even after the project is gone.

## Before you delete

- Export what you need first, such as invoice PDFs, the [DDV evidence](slovenia/ddv-evidence) or the [books](accounting/journal).
- Only the owner can delete a project.

## Delete it

Open **Settings** and scroll to the bottom. Press **Delete this project**.

![The Delete project card](https://cdn.rabbitpay.net/help/en/dark/settings/delete-project/card.webp)

Confirm with **Delete project**.

![The confirmation](https://cdn.rabbitpay.net/help/en/dark/settings/delete-project/confirm.webp)

The project stops appearing anywhere, for you and your team. This cannot be undone from RabbitPay.
