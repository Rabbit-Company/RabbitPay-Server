# Inventory

Keep stock by item and warehouse, value it by FIFO or average cost, count it once a year and let every sale reduce it on its own.

## Set up

| Step | Page                                                 |
| ---- | ---------------------------------------------------- |
| 1    | [Start keeping stock](inventory/start)               |
| 2    | [Choose how stock is valued](inventory/settings)     |
| 3    | [Add your suppliers](inventory/suppliers-and-orders) |

## Day to day

| I want to                                            | Page                                                            |
| ---------------------------------------------------- | --------------------------------------------------------------- |
| Book goods that arrived                              | [Receive goods](inventory/receive-goods)                        |
| Order from a supplier and know what is on its way    | [Suppliers and purchase orders](inventory/suppliers-and-orders) |
| Know what happens when I sell                        | [Sales and returns](inventory/sales)                            |
| Write off damaged goods or take something for myself | [Issue stock for other reasons](inventory/issue-stock)          |
| Move goods to another warehouse                      | [Warehouses and transfers](inventory/warehouses-and-transfers)  |
| Count the stock at the end of the year               | [Stocktake](inventory/stocktake)                                |
| See stock and its value on a date                    | [Stock reports](inventory/stock-reports)                        |

Inventory is a separate license. Redeem an inventory key on the **License** page and **Inventory** appears in the project menu.
