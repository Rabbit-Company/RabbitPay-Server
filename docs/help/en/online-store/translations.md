# Translations

English and Slovenian are built in. You can add up to 10 languages in total, translate them at your own pace and show each one when it is ready.

Open **Store** > **Translations**.

![The languages of the store](https://cdn.rabbitpay.net/help/en/dark/online-store/translations/languages.webp)

## Add a language

Under **Add language**, enter the **Language code**, for example `it` or `de`, and the **Name shown to shoppers**, then press **Add language**. A new language stays hidden until you press **Show in store**.

## What to translate

- **Edit texts** changes any text the store shows, from buttons to checkout labels. Built-in languages come translated, you can still change any text.
- Product and category names and descriptions are translated where you write them, on a tab for each language.

A text you leave empty is shown in the default language.

Orders, invoices and order emails stay in the default language of the store.
