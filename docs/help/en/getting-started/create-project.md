# Create a project

A project is one business. It has its own customers, invoices, numbering, payment methods and team. If you run two businesses, create a project for each, and their invoices and numbers never mix.

## Create the project

1. On **Projects**, press **New project**.

   ![The Projects page, with New project in the top right corner](https://cdn.rabbitpay.net/help/en/dark/getting-started/create-project/projects-empty.webp)

2. Enter the **Business name**. This is the name your customers see on invoices and on the page they pay from, for example `Harbour Lane Studio`.
3. Check the **Project name**. RabbitPay fills it in from the business name. It is a short name for web addresses, written in lowercase letters, numbers and hyphens, 4 to 30 characters long.
4. Press **Create project**.

   ![Naming the new project](https://cdn.rabbitpay.net/help/en/dark/getting-started/create-project/new-project.webp)

## Look at your new project

The project opens on **Overview**, which counts your invoices, customers, team members and transactions, lists your latest invoices and tells you when something needs your attention. A new project reminds you that no payment method is switched on yet. You do that in [Your first invoice](getting-started/first-invoice#tell-customers-where-to-pay).

![The Overview of a new project](https://cdn.rabbitpay.net/help/en/dark/getting-started/create-project/overview.webp)

## Find the project again

Every project you own or were invited to is listed on **Projects**, the first page after you sign in. Press its card to open it.

![The new project on the Projects page](https://cdn.rabbitpay.net/help/en/dark/getting-started/create-project/project-card.webp)

## Change the name or the currency

1. In the project menu on the left, press **Settings**.
2. Under **Details**, change the **Display name** your customers see, or the short **Project name**.
3. Check the **Primary currency**. New invoices and the terminal start in this currency.
4. Press **Save changes**.

   ![The Details card in Settings](https://cdn.rabbitpay.net/help/en/dark/getting-started/create-project/details.webp)

## API keys, if you connect other software

You can skip this unless a developer asks you for an API key. API keys let other software, such as your web shop, create invoices in this project.

1. Open **Settings** and find the card **API keys**.
2. Press **Rotate** next to the key you want and confirm.
3. Copy the new key and store it in your password manager. It is shown only once.

   ![The API keys card in Settings](https://cdn.rabbitpay.net/help/en/dark/getting-started/create-project/api-keys.webp)

Rotating a key stops the old one at once, so anything that used it has to be given the new key.
