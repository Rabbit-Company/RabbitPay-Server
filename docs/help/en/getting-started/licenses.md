# What is included

You can issue invoices and take payments in RabbitPay for free. This page shows where you see what your project includes, and how you add more with a license key.

## Open License

In the project menu, press **License**.

![License in the project menu](https://cdn.rabbitpay.net/help/en/dark/getting-started/licenses/open-license.webp)

## See what is running

**Timeline** shows what is active in your project today and what is scheduled, three months ahead.

![The timeline of a new project](https://cdn.rabbitpay.net/help/en/dark/getting-started/licenses/timeline.webp)

| Line                 | What it unlocks                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------------ |
| **White label**      | Your own logo and email server, and no RabbitPay name on what customers see                                  |
| **Online store**     | Your own web store. See [Online store](online-store)                                                         |
| **Workforce**        | Timesheets, absences, tickets, chat, employees and payroll. See [Timesheets, tickets and payroll](workforce) |
| **Accounting**       | Simplified or double entry books, a fixed asset register and year end reports                                |
| **Inventory**        | Stock by warehouse with FIFO or average cost. See [Inventory](inventory)                                     |
| **Document storage** | Room for archived invoices, credit notes and expense attachments                                             |

## See how much you have used

**Payments this month** counts the completed payments of the month against the free ones, and shows your paid balance. Free payments start again on the first day of every month. A paid balance never expires.

![Payments used and left this month](https://cdn.rabbitpay.net/help/en/dark/getting-started/licenses/payments.webp)

The cards below it do the same for emails, document storage and file storage.

## Redeem a license key

1. Under **Redeem a license**, paste the key you bought.
2. Press **Check key** to see what it adds before anything changes.
3. Redeem it. A key that runs for a number of days can start today, when the current one ends, or on a date you choose.

   ![Redeeming a license key](https://cdn.rabbitpay.net/help/en/dark/getting-started/licenses/redeem.webp)

The card also says who sells license keys for this server and shows the **Server ID** to give them when you buy.
