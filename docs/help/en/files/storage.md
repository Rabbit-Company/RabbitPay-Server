# Storage and limits

See what takes up file storage and set how much each person may use.

## Limits

Files use the same **File storage** as ticket attachments. Owners and administrators open **Storage and limits** to see every file, largest first, and to set:

1. **Largest file in MB**, the biggest single file anyone can upload.
2. **Storage per person in MB**, how much each person can keep in Files and send as chat attachments and recordings. Leave it empty for no limit.
3. An **own limit** for one person, when someone needs more or less than the others.

![Storage and limits](https://cdn.rabbitpay.net/help/en/dark/files/storage/limits.webp)

## Chat attachments

**My chat attachments** in **Files** lists everything you sent in chat, with its size, the conversation and the date. Remove one with **Remove**, or remove all of yours older than a chosen age. Owners and administrators see chat attachments under **Storage and limits** with the size, the sender and the date, but cannot open them.

![My chat attachments](https://cdn.rabbitpay.net/help/en/dark/files/storage/chat-attachments.webp)
