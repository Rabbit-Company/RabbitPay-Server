# Datoteke

Dokumente, slike in videe hranite na enem skupnem mestu, v mapah, in jih delite s tistimi, ki jih potrebujejo.

## Strani

| Stran                                 | Kaj pokriva                                                                              |
| ------------------------------------- | ---------------------------------------------------------------------------------------- |
| [Hranjenje datotek](files/keep-files) | Ustvarite mape, naložite datoteke in jih odprite brez prenosa.                           |
| [Deljenje datotek](files/share)       | Mapo ali posamezno datoteko delite z vsemi ali z izbranimi osebami.                      |
| [Prostor in omejitve](files/storage)  | Poglejte, kaj zaseda prostor za datoteke, in določite, koliko lahko uporabi vsaka oseba. |
