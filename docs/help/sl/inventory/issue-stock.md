# Izdaja zaloge iz drugih razlogov

Za vse, kar zapusti zalogo brez prodaje, uporabite **Več dokumentov** > **Nova izdajnica**.

## Vnesite izdajnico

1. Izberite **Razlog**. Besedilo pod njim pove, kaj se zgodi.
2. Dodajte artikle in količine. Pod vsako vrstico je prikazana trenutna zaloga.
3. Pod **Opombe** zapišite, kaj se je zgodilo.
4. Pritisnite **Knjiži** in potrdite.

![Odpis dveh poškodovanih plakatov](https://cdn.rabbitpay.net/help/sl/dark/inventory/issue-stock/issue.webp)

![Knjižena izdajnica](https://cdn.rabbitpay.net/help/sl/dark/inventory/issue-stock/posted.webp)

## Kateri razlog

| Razlog                                                 | Pomen                                                                                |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| **Poraba v podjetju**                                  | Material ali blago, porabljeno pri delu. Postane strošek materiala.                  |
| **Poškodba ali lom**, **Pretečen rok ali zastarelost** | Odpis. Hranite zapisnik o uničenju.                                                  |
| **Kalo v okviru normativa**                            | Izguba v okviru normativa pristojnega združenja. DDV se ne obračuna.                 |
| **Primanjkljaj nad dovoljenim kalom**                  | Šteje se za dobavo, zato se obračuna DDV od nabavne vrednosti.                       |
| **Lastna raba**                                        | Vzeto za zasebne namene. Praviloma se obračuna DDV od nabavne vrednosti.             |
| **Darilo ali vzorec**                                  | Podarjeno. Praviloma se obračuna DDV, razen pri vzorcih in darilih manjše vrednosti. |
| **Tatvina**                                            | Brez DDV, če je sestavljen policijski zapisnik.                                      |
| **Višja sila**                                         | Požar, poplava ali podoben dogodek. DDV se ne obračuna.                              |
| **Vračilo dobavitelju**                                | Vrnjeno blago. Dobropis dobavitelja vnesite kot nabavo zalog.                        |

Kadar se DDV obračuna, pustite vklopljeno **Obračunaj DDV od nabavne vrednosti**. DDV se knjiži in vpiše v evidence DDV kot interni dokument.

## Stornirajte dokument

Knjiženega dokumenta ni mogoče spremeniti. Odprite ga, pritisnite **Storniraj dokument** in navedite razlog.

![Storniranje dokumenta](https://cdn.rabbitpay.net/help/sl/dark/inventory/issue-stock/cancel.webp)

Njegovi premiki se odstranijo, vse kasnejše izdaje se ponovno ovrednotijo, knjižba v glavni knjigi pa se stornira. Dokument ostane na seznamu kot storniran in obdrži številko. Nato vnesite nov, pravilen dokument. To velja za vse vrste dokumentov.
