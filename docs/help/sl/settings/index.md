# Nastavitve

Vse nastavitve projekta in stran, ki jih razloži, kartico za kartico, ter nastavitve vašega uporabniškega računa.

## Nastavitve projekta

V meniju projekta pritisnite **Nastavitve**. Stran je stolpec kartic. Večino lahko spreminjajo le lastniki in skrbniki.

![Nastavitve v meniju projekta](https://cdn.rabbitpay.net/help/sl/dark/settings/index/nav.webp)

| Kartica                               | Kaj nastavi                                                                  | Stran                                                                                               |
| ------------------------------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| **Podatki**                           | Ime projekta, prikazno ime in glavno valuto                                  | [Spremenite ime ali valuto](getting-started/create-project#spremenite-ime-ali-valuto)               |
| **Podatki podjetja**                  | Uradno ime, naslov, davčno in matično številko, nogo računa                  | [Vpišite podatke podjetja](getting-started/company-details#vpisite-podatke-podjetja)                |
| **Račun**                             | Jezik, obliko datuma in ure, računovodski časovni pas, izdajatelja in podpis | [Jezik, datumi in izdajatelj](settings/documents)                                                   |
| **Oblikovanje računov**               | Postavitev, pisavo, barve in besedila računov                                | [Oblikovanje in besedila](invoices/design)                                                          |
| **Oblikovanje e-pošte**               | Barve, logotip in besedila e-pošte                                           | [Oblikovanje in besedila](invoices/design#spremenite-videz-e-poste)                                 |
| **Številčenje dokumentov**            | Številčenje računov, predračunov in naročil                                  | [Številke računov](invoices/numbering)                                                              |
| **Davki**                             | Državo, status DDV, valuto poročanja, OSS                                    | [Nastavite, kako za vas velja DDV](getting-started/company-details#nastavite-kako-za-vas-velja-ddv) |
| **Davčno potrjevanje računov (FURS)** | Potrdilo, poslovne prostore in naprave, samo v Sloveniji                     | [Davčno potrjevanje računov](slovenia/fiscal-verification)                                          |
| **Podpisovanje e-računov**            | Potrdilo, s katerim se podpisujejo e-računi e-SLOG                           | [Podpisujte e-račune](slovenia/e-invoices#podpisujte-e-racune)                                      |
| **Poudarna barva**                    | Barvo gumbov na strani za plačilo in v tem projektu                          | [Barva blagovne znamke](settings/brand-color)                                                       |
| **E-pošta**                           | Kaj vsebuje e-pošta in samodejne opomnike                                    | [Samodejno pošiljanje opomnikov](invoices/send#samodejno-posiljanje-opomnikov)                      |
| **Blagajna**                          | Ali lahko blagajniki vpišejo svoje zneske                                    | [Blagajniki in nastavitve](terminal/terminal-settings)                                              |
| **Načini plačila**                    | Bančno nakazilo, kartice, PayPal in kripto                                   | [Načini plačila](payments/payment-methods)                                                          |
| **API ključi** in **Webhooki**        | Povezavo z drugo programsko opremo                                           | [API ključi in webhooki](settings/api-keys-and-webhooks)                                            |
| **Izbriši projekt**                   | Odstranitev projekta                                                         | [Izbris projekta](settings/delete-project)                                                          |

## Vaš uporabniški račun

Pritisnite svoj e-poštni naslov v zgornjem desnem kotu in izberite **Varnost računa**. Zavihek **Varnost** ima vaše geslo in drugi korak prijave. Zavihek **Obvestila** izbere, o čem vas RabbitPay obvešča.

Glejte [Zaščitite svoj račun](getting-started/secure-your-account) in [Izberite obvestila](getting-started/notifications).
