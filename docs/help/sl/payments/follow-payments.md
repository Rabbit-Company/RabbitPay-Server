# Spremljajte plačila

**Plačila** na enem mestu naštejejo vsa plačila in vsa vračila projekta, ne glede na to, kako je denar prispel.

## Odprite Plačila

V meniju projekta pritisnite **Plačila**.

![Plačila v meniju projekta](https://cdn.rabbitpay.net/help/sl/dark/payments/follow-payments/open-payments.webp)

## Preberite seznam

![Seznam plačil](https://cdn.rabbitpay.net/help/sl/dark/payments/follow-payments/payments.webp)

Vrstica nad tabelo za prikazane vrstice sešteje, koliko je bilo prejeto in vrnjeno ter kolikšne so bile provizije.

| Stolpec           | Kaj pokaže                                                                         |
| ----------------- | ---------------------------------------------------------------------------------- |
| **Vrsta**         | **Plačilo** ali vračilo                                                            |
| **Znesek**        | Koliko je prispelo ali koliko je bilo vrnjeno, z znakom minus                      |
| **Način plačila** | Kako je bilo plačano, pod tem pa bančni sklic ali ID ponudnika                     |
| **Stanje**        | **Zaključeno** se šteje za račun. **V čakanju** je bilo opaženo, a se še ne šteje. |
| **Račun**         | Račun, ki mu pripada. Pritisnite ga, da odprete račun.                             |
| **Kupec**         | Kdo je plačal                                                                      |
| **Kdaj**          | Datum in ura plačila                                                               |

## Poiščite plačilo

| Filter                       | Kaj naredi                                            |
| ---------------------------- | ----------------------------------------------------- |
| **Račun ali ID transakcije** | Poišče plačilo po številki računa ali ID-ju ponudnika |
| **Vse vrste**                | Pokaže samo plačila ali samo vračila                  |
| **Vsa stanja**               | Pokaže samo eno stanje, na primer v čakanju           |
| **Vsi načini plačila**       | Pokaže samo en način plačila, na primer Stripe        |
| **Vsi kupci**                | Pokaže plačila enega kupca                            |

![Seznam, ki kaže samo vračila](https://cdn.rabbitpay.net/help/sl/dark/payments/follow-payments/refunds.webp)

## Plačila, ki so še v čakanju

Plačilo s kriptovaluto je v čakanju od trenutka, ko je opaženo, dokler nima dovolj potrditev. Nato postane zaključeno in račun je poravnan. Ni vam treba narediti ničesar.

## Zabeležite ali vrnite plačilo

Oboje naredite na računu, ne na tem seznamu.

- Bančno nakazilo ali gotovino zabeležite tako, da odprete račun in pritisnete **Zabeleži plačilo**. Glejte [Zabeležite plačilo](invoices/record-payment).
- Denar vrnete tako, da odprete račun in ob plačilu pritisnete **Vrni**. Glejte [Vrnite denar](invoices/record-payment#vrnite-denar).

## Poglejte seštevke na prvi pogled

**Pregled** projekta šteje vaše račune, kupce in transakcije ter našteje zadnje račune z njihovim stanjem.

![Pregled projekta v uporabi](https://cdn.rabbitpay.net/help/sl/dark/payments/follow-payments/overview.webp)

Za prihodke skozi čas, po kupcih ali po artiklih glejte [Stroški in poročila](expenses-and-reports).
