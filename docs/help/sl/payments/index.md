# Plačila

Izberite, kako lahko vaši kupci plačajo, in spremljajte denar, ko prihaja. Plačila gredo naravnost na vaš račun, k vašemu ponudniku plačil ali v vašo denarnico, nikoli prek RabbitPaya.

## Nastavite način plačila

| Način                     | Zabeleženo | Stran                                     |
| ------------------------- | ---------- | ----------------------------------------- |
| Bančno nakazilo           | Ročno      | [Bančno nakazilo](payments/bank-transfer) |
| Kartice, prek Stripa      | Samodejno  | [Kartice s Stripom](payments/cards)       |
| PayPal                    | Samodejno  | [PayPal](payments/paypal)                 |
| Bitcoin, Ethereum, Monero | Samodejno  | [Kriptovalute](payments/crypto)           |

Začnite s stranjo [Načini plačila](payments/payment-methods), ki razloži kartico, v kateri vse vklopite.

## Prodajajte osebno z blagajno

**Blagajna** spremeni telefon, tablico ali napravo POS v blagajno, z gotovino in drobižem, kodo QR za plačilo s telefonom ter natisnjenimi ali poslanimi računi. Glejte [Blagajna](terminal).
