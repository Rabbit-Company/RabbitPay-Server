# Stroški in poročila

Beležite, kaj vaše podjetje porabi, uvozite račune dobaviteljev brez prepisovanja, plačajte dobaviteljem v enem paketu ter poglejte prihodke, stroške in DDV drug ob drugem.

## Beležite, kaj porabite

| Želim                                          | Stran                                                           |
| ---------------------------------------------- | --------------------------------------------------------------- |
| Vnesti račun dobavitelja ali potrdilo          | [Zabeležite strošek](expenses-and-reports/record-expense)       |
| Uvoziti e-račun dobavitelja                    | [Uvozite e-račun](expenses-and-reports/import-e-invoice)        |
| Uvoziti več stroškov iz preglednice            | [Uvoz iz CSV](expenses-and-reports/import-csv)                  |
| Samodejno vnašati najemnino in naročnine       | [Ponavljajoči stroški](expenses-and-reports/recurring-expenses) |
| Plačati več dobaviteljem hkrati iz svoje banke | [Plačajte dobaviteljem](expenses-and-reports/pay-suppliers)     |

## Poglejte, kako gre podjetju

| Želim                                           | Stran                                                        |
| ----------------------------------------------- | ------------------------------------------------------------ |
| Videti prihodke, stroške in dobiček             | [Prihodki in stroški](expenses-and-reports/financial-report) |

| Videti, kateri izdelki in storitve se prodajajo | [Prodaja artiklov](expenses-and-reports/item-sales)          |

## Kdo lahko kaj

Lastniki, skrbniki, vodje in računovodje lahko beležijo in urejajo stroške. Brisati jih lahko le lastniki in skrbniki. **Statistiko** lahko odprejo vsi, ki lahko vidijo poročila.
