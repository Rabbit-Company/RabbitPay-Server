# Knjigovodstvo

Vodite knjige slovenske družbe ali samostojnega podjetnika v istem projektu, iz katerega izdajate račune. Listine se knjižijo same.

RabbitPay vodi dvostavno knjigovodstvo po slovenskih računovodskih standardih (SRS). Računi, plačila, stroški, plače in zaloge se knjižijo sami, zato predvsem preverjate, povezujete in zaključujete.
