# Klepet in klici

Pišite sodelavcem, pošiljajte datoteke, pokličite eno osebo ali skupino, načrtujte sestanke z gosti in snemajte klice.

## Strani

| Stran                                                | Kaj pokriva                                                                               |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| [Pogovori](chat/conversations)                       | Pišite sodelavcem v projektu in poglejte, kdo je ta trenutek dosegljiv.                   |
| [Skupine](chat/groups)                               | Pogovarjajte se z več sodelavci hkrati v poimenovani skupini.                             |
| [Oblikovanje in datoteke](chat/formatting-and-files) | Oblikujte sporočila, pošiljajte kodo ter pripenjajte datoteke in posnetke zaslona.        |
| [Klici](chat/calls)                                  | Pokličite sodelavca z glasom ali sliko, delite zaslon ali začnite klic v skupini.         |
| [Sestanki in gostje](chat/meetings)                  | Načrtujte sestanek za določen čas in ljudem zunaj ekipe omogočite pridružitev s povezavo. |
| [Snemanje klica](chat/recording)                     | Posnemite klic ali sestanek z glasovi vseh in deljenim zaslonom.                          |
