# Vloge

Ljudi povabite pod **Ekipa** in vsakemu dodelite vlogo. Kako pošljete povabilo, preberite v [Povabite ekipo](getting-started/invite-team).

![Ekipa z zaposlenim in nadzornico](https://cdn.rabbitpay.net/help/sl/dark/workforce/roles/team.webp)

## Kaj lahko počne katera vloga

| Vloga     | Kaj lahko počne                                                               |
| --------- | ----------------------------------------------------------------------------- |
| Zaposleni | Beleži svoje ure in odsotnosti ter dela na zahtevkih                          |
| Nadzornik | Upravlja evidence, odsotnosti in zahtevke vseh ter pripravlja poročila o urah |
| Vodja     | Dela z zahtevki, ne pa z evidencami delovnega časa                            |

Lastniki in administratorji lahko naredijo vse, kar nadzornik. Podatki o zaposlenih in plače imajo svoja dovoljenja, zato nadzornik vidi ure, ne pa plač.
