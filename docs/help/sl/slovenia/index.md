# Slovenska zakonodaja

Kaj slovensko podjetje nastavi v RabbitPayu: davčno potrjevanje računov pri FURS, e-račune, podatke, ki jih zakon zahteva na vsakem računu, in evidence DDV, ki jih oddate v eDavkih.

Vse na tej strani velja za projekte, ki imajo za davčno državo izbrano Slovenijo. Izberete jo skupaj s statusom DDV v **Nastavitve** > **Davki**, kot je opisano v [Podatki podjetja](getting-started/company-details). Slovenski projekt DDV vedno poroča v evrih.

## Nastavite enkrat

| Želim                                                  | Stran                                                        |
| ------------------------------------------------------ | ------------------------------------------------------------ |
| Sprejemati gotovino, kartice ali kripto s potrjevanjem | [Davčno potrjevanje računov](slovenia/fiscal-verification)   |
| Na računih izpisati vpis v register in osnovni kapital | [Obvezni podatki podjetja](slovenia/company-details)         |
| Podpisovati e-račune                                   | [e-Računi (e-SLOG)](slovenia/e-invoices#podpisujte-e-racune) |

## Vsak dan

| Želim                                         | Stran                                                       |
| --------------------------------------------- | ----------------------------------------------------------- |
| Preveriti, ali je račun prišel do FURS        | [Računi, poslani FURS](slovenia/verified-invoices)          |
| Poslati e-račun podjetju ali javnemu sektorju | [e-Računi (e-SLOG)](slovenia/e-invoices)                    |
| Zaračunati gradbena dela brez DDV             | [Domača obrnjena davčna obveznost](slovenia/reverse-charge) |
| Izdati račun v dolarjih ali za pretekli mesec | [Obdobja DDV in tuje valute](slovenia/vat-periods)          |
| Oddati KIR in KPR v eDavkih                   | [Evidence DDV za eDavke](slovenia/ddv-evidence)             |

Prodajate v trgovini ali na stojnici? Tudi [Blagajna](terminal) deluje z davčnim potrjevanjem.

Podprta so samo običajna pravila DDV. Obračunavanje DDV po plačani realizaciji, posebna ureditev za prodajo rabljenega blaga in samofakturiranje niso podprti.
