# Security policy

## Reporting a vulnerability

Please do not report security issues in public issues.

Report them privately through
[GitHub private vulnerability reporting](https://github.com/Rabbit-Company/RabbitPay-Server/security/advisories/new)
or by email to [info@rabbitpay.net](mailto:info@rabbitpay.net).

Include what you can of the following:

- the affected area, endpoint or file
- steps to reproduce, or a proof of concept
- the impact you expect, for example which data or payments are exposed
- the version or commit you tested, and whether it was rabbitpay.net or a self-hosted server

You will get a reply within 3 business days. We will keep you updated while the
issue is fixed and credit you in the advisory unless you ask us not to.

## Scope

Both the hosted service at [rabbitpay.net](https://rabbitpay.net) and self-hosted
servers are in scope. When testing rabbitpay.net, use only accounts and data you
own, and do not run automated scans or load tests against it.

## Supported versions

Security fixes are made on the latest release. Self-hosted servers should update
to it to receive them.
